# Deskapp

Electron + Vue 3 desktop app built with the Deskapp framework.

## Quick Start

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - Run in development mode
- `npm run build` - Build the app
- `npm run package` - Package the app with electron-builder
- `npm run maker` - Run the maker CLI

## Structure

- `src/main.ts` - Electron main process
- `src/preload.ts` - Preload script
- `src/ui/` - Vue 3 frontend
- `src/modules/` - Your application modules
- `src/core/` - Framework core
